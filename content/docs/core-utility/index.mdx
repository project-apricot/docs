# Core Utility

`ApricotFramework.CoreUtility` is a small, **zero-dependency** library of helpers that
extend the .NET base class library.

The package takes no dependencies at all, so adding it never drags anything transitive
into your application.

## Install

```bash
dotnet add package ApricotFramework.CoreUtility
```
